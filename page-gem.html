สร้าง GEM

สร้างผู้ช่วย AI ส่วนตัวใน Gemini พร้อมกฎความปลอดภัย

ใบงาน 4 ช่อง ป้องกัน Prompt Injection
พบงานที่ทำค้างไว้ในหน้านี้
ตอบ 4 คำถามตามใบงาน Input → Process → Output → Check ระบบจะเขียน Instruction ให้ครบชุด พร้อมระบบป้องกัน Prompt Injection ที่ใส่ให้อัตโนมัติทุกครั้ง
1. Input ข้อมูลตั้งต้น 2. Process ขั้นตอนคิด 3. Output รูปแบบผลลัพธ์ 4. Check เกณฑ์ตรวจความถูกต้อง + เกราะป้องกันอัตโนมัติ
กำหนดบทบาทและชื่อผู้ช่วย GEM ระบุงานหลักที่ต้องการให้ผู้ช่วยทำซ้ำ และตั้งชื่อประจำตัวให้จำง่าย
Input ขั้นที่ 1 · ข้อมูลเข้า
คุณต้องให้ข้อมูลอะไร AI บ้าง?
Process ขั้นที่ 2 · วิธีทำงาน

Output ขั้นที่ 3 · ผลลัพธ์
ผลลัพธ์หน้าตาเป็นอย่างไร? ส่งใคร?
Check ขั้นที่ 4 · ตรวจคุณภาพ
จะรู้ได้อย่างไรว่าทำถูก?
ป้องกัน Prompt Injection — ระบบใส่ให้อัตโนมัติ จุดเด่นของคอร์สนี้: GEM ทุกตัวที่สร้างจากที่นี่จะมีเกราะป้องกันคนที่พยายามหลอกให้ AI ทำนอกหน้าที่ หรือขโมยคำสั่งของคุณ

    อัปเดตอัตโนมัติ

    คัดลอกข้อความนี้ไปวางในช่อง "คำสั่ง (Instructions)" ตอนสร้าง Gem ใน Gemini (เปลี่ยนตัวเลือกด้านบนได้ตลอด ข้อความจะอัปเดตให้เอง)

    ขั้นต่อไป: เปิดหน้าสร้าง Gem (ระบบจะคัดลอก Instruction ให้อัตโนมัติ แล้วไปวางในช่อง "คำสั่ง" ได้เลย) — บนมือถือจะเปิดแอป Gemini โดยตรง แล้วไปที่เมนู Gems

    เปิดหน้าสร้าง Gem ใน Gemini ใช้กับ ChatGPT (Custom GPT)

    ไปต่อที่เกี่ยวข้อง
